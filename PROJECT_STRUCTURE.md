
# Project Structure

## Overview

This document describes the organization of the GBitcoin (GBTC) website repository and explains the purpose of its main directories and files.

The structure is designed to keep the project organized, maintainable, and accessible to developers and contributors.

```text

├── css/
```

## Main Files

### index.html

The main entry point of the website.

It contains the website structure, content sections, metadata, and references to the required stylesheets and scripts.

### CSS Directory

The `css/` directory contains the website's styling resources.

- `styles.css`: Main website styles and layout rules.
- `gemstone.css`: Additional visual styling and gemstone-inspired design elements.

### JavaScript Directory

The `js/` directory contains the website's client-side functionality.

- `main.js`: Main interactive website functionality.
- `language.js`: Language translations and localization functionality.

### Assets Directory

The `assets/` directory stores visual resources used by the website.

- `gbtc-logo.png`: GBitcoin logo asset.

## Documentation Files

The repository root contains documentation covering:

- Project overview and introductory information.
- Copyright and licensing notices.
- Security reporting procedures.
- Contribution guidelines.
- Community standards.
- Project governance principles.
- Whitepaper and project vision.
- Disclaimers and risk information.
- Development history and release notes.
- Acknowledgments and support information.
- Frequently asked questions.
- Repository structure and organization.

## Maintenance

The repository structure may evolve as GBitcoin develops.

This document should be updated whenever significant changes are made to the directory layout, main files, or project organization.

Only files and directories that actually exist in the repository should be documented as part of its current structure.
