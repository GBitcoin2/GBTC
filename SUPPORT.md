
# Support

## Overview

This document explains how to seek assistance, report issues, and communicate questions related to the GBitcoin (GBTC) project.

## Getting Help

For general questions, project information, or development-related inquiries, please use the official GBitcoin communication channels.

- **Official Website:** https://gbitcoin2.github.io/GBTC-website/
- **Official X:** https://x.com/GBitcoin2

## Reporting Issues

If you discover a technical issue or unexpected behavior in the project, please provide a clear description that includes:

- A summary of the issue.
- Steps to reproduce it, when applicable.
- Expected behavior.
- Actual behavior.
- Relevant screenshots or error messages, if available.

Please avoid sharing passwords, private keys, recovery phrases, wallet credentials, or other sensitive information.

## Security Matters

For potential security vulnerabilities, please follow the instructions in [SECURITY.md](SECURITY.md) rather than publicly disclosing sensitive technical details.

## Feature Requests and Suggestions

Constructive suggestions and feature requests are welcome.

Please explain the proposed improvement, the problem it addresses, and how it could benefit the project.

## Response Expectations

The project may not provide immediate responses or guarantee support, maintenance, or resolution for every inquiry.

Support availability may change as the project develops.

## Important Notice

GBitcoin does not provide individual financial, investment, legal, or tax advice through its support channels.

Always verify project information through official sources and exercise caution when interacting with digital assets.
